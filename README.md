# 🔢 Scientific Calculator (Python CLI)

## 📌 Overview

This project is a **Scientific Calculator built using Python** that runs in the command-line interface (CLI).
It supports both basic arithmetic operations and advanced mathematical functions such as trigonometry and logarithms.

The program continuously runs in a loop until the user chooses to exit, making it interactive and user-friendly.

---

## 🚀 Features

### ➕ Basic Operations

* Addition
* Subtraction
* Multiplication
* Division (with zero-division handling)

### 🧮 Advanced Operations

* Power (a^b)
* Square Root
* Modulus

### 📐 Trigonometric Functions

* sin(x)
* cos(x)
* tan(x)
  *(Input in degrees, internally converted to radians)*

### 📊 Logarithmic Functions

* log₁₀(x) (base 10)
* ln(x) (natural logarithm)

### 🔁 Other Features

* Continuous loop until exit
* Error handling for invalid inputs
* Handles edge cases (negative numbers, zero division)
